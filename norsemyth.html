ニーベルングの指環

学んだこと
リヒャルト・ワーグナーが35歳の1848年から61歳の1874年にかけて作曲した北欧神話をもとにしたオペラである

あらすじ：小人族のアルベリヒはライン川の底に沈む世界を支配する力を持つラインの黄金を三姉妹から強奪してしまう

オーディンは宮殿ができたときに目覚めた。フライヤを、宮殿を建設した褒美として巨人と結婚させようとしていた。しかし、それはオーディンの詐欺でフライヤを最初から巨人と結婚させる気などなかった。オーディンはロキと結託してしまう。巨人はロキの口車に載せられて「代わりにラインの黄金をくれたら許してやる」と約束してしまう。しかし、オーディンが約束をまた破るんじゃないかと思った巨人はフライヤを連れ去ってしまう。オーディンはしかたなくロキとラインの黄金を探すことに。

アルベリヒはラインの黄金を指輪に変えていて、その力で地下世界を支配していた。しかし、アルベリヒはロキとオーディンに戦いで負けて、指輪を渡してしまう。オーディンが立ち去ろうとした瞬間にアルベリヒは指輪に呪いをかけてしまう。オーディンはフライヤとラインの黄金の指環を無事に交換する

ラインの黄金でできた指輪を得た巨人はその指輪の力ゆえに殺し合いを始めてしまう。生き残ったファーフナーが指輪を奪ってしまう

（R：ラインの黄金、W：ワルキューレ、S：ジークフリート、G：神々の黄昏）

ヴェルグンデ、ヴォークリンデ、フロスヒルデ (R, G) : ラインの娘たち。ラインの黄金を守る三姉妹。

アルベリヒ (R, S, G) : 小人。ニーベルング族の長。ラインの黄金を盗み出す。

ヴォータン（オーディン） (R, W, S) : 神々の長。

フリッカ (R, W) : ヴォータンの正妻。「結婚」の守護神。

フライア (R) : 女神。フリッカの妹。

ファーゾルト (R) : 巨人。ヴァルハラを建てた代償としてフライアを連れ去る。

ファーフナー (R, S) : 巨人。ファーゾルトの弟。龍に変化する。

ローゲ（ロキ） (R) : 狡猾な半神。火を司る。

エルダ (R, S) : 知恵の女神、地母神。

ジークムント (W) : ヴォータンが人間女性との間に儲けた男子。ヴェルズング族。ジークフリートの父。

ジークリンデ (W) : ジークムントの双子の妹。ジークフリートの母。

フンディング (W) : ヴェルズング族と敵対する一族の男。ジークリンデの夫。

ブリュンヒルデ (W, S, G) : ヴォータンとエルダの娘で英雄をヴァルハラに導くワルキューレの一人で、ヴォータンが最愛とする。ジークフリートの妻になる。

ミーメ (R, S) : アルベリヒの弟。ジークフリートを育てる。

ジークフリート (S, G) : 人間の英雄。竜（ファーフナー）の血を浴び、不死身となる。

ノルン (G) : 運命を司る三人の女神。エルダの娘。

グンター (G) : ギービッヒ家の当主

グートルーネ (G) : グンターの妹。ジークフリートと偽りの結婚をする。

ハーゲン (G) : アルベリヒの子。グンターの異父兄弟。

考えたこと
力を手に入れることができる指輪で狂ってしまう神々や人々の悲劇のオペラ。北欧神話が好きなので、やっぱりオーディンとロキか……と思ってしまった。ファーフナーはなぜ竜になったのか？　指輪はその後どうなったのか？　この指輪がのちのロードオブザリング？
